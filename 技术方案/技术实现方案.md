> **项目目标**：构建基于机器学习的直播销量预测系统，融合多源数据，替代人工经验预测，服务供应链智能决策。

## 三、特征工程设计

### 3.1 特征分类

| 类别 | 特征名称 | 数据来源 | 类型 | 说明 |
|---|---|---|---|---|
| **历史销量** | 近7/14/30天日均销量 | ERP | 数值 | 短期趋势 |
| | 同期(去年)销量 | ERP | 数值 | 季节性 |
| | 近3个月销量标准差 | ERP | 数值 | 波动性 |
| **主播特征** | 主播粉丝量级 | 平台API | 数值 | 影响力 |
| | 主播近7天场均GMV | 平台API | 数值 | 近期表现 |
| | 主播历史同类目转化率 | 平台API | 数值 | 带货能力 |
| | 主播档期类型(专场/混场) | 商务 | 类别 | 流量集中度 |
| **商品特征** | 商品价格 / 折扣力度 | SIM | 数值 | 价格弹性 |
| | 商品类目(美妆/食品/日用) | SIM | 类别 | 品类差异 |
| | 是否为新品 | SIM | 布尔 | 新品风险 |
| | SKU历史退货率 | ERP | 数值 | 品质信号 |
| **流量特征** | 直播前3天加购量 | 平台API | 数值 | 最强前置信号 |
| |预热视频播放量/互动量 | 平台API | 数值 | 预热效果 |
| | 平台是否百亿补贴 | 运营 | 布尔 | ±30%偏差 |
| **竞品特征** | 竞品是否同期直播 | 爬虫 | 布尔 | 分流风险 |
| | 竞品折扣力度 | 爬虫 | 数值 | 价格战 |
| **时间特征** | 是否周末/节假日 | 日历 | 布尔 | 流量差异 |
| | 是否618/双11 | 日历 | 布尔 | 大促叠加 |
| | 直播时段(晚间/白天) | 平台 | 类别 | 流量差异 |

### 3.2 特征工程代码示例

```python
import pandas as pd
import numpy as np
from sklearn.preprocessing import LabelEncoder, StandardScaler

class LiveStreamFeatureEngineer:
    """直播电商销量预测特征工程"""

    def __init__(self):
        self.label_encoders = {}
        self.scaler = StandardScaler()

    def build_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """构建完整特征集"""
        features = pd.DataFrame()

        # ===== 历史销量特征 =====
        features['sales_7d_avg'] = df['sales'].rolling(7).mean()
        features['sales_14d_avg'] = df['sales'].rolling(14).mean()
        features['sales_30d_avg'] = df['sales'].rolling(30).mean()
        features['sales_7d_std'] = df['sales'].rolling(7).std()
        features['sales_trend'] = features['sales_7d_avg'] / features['sales_30d_avg']

        # ===== 主播特征 =====
        features['anchor_fans_log'] = np.log1p(df['anchor_fans'])
        features['anchor_7d_avg_gmv'] = df['anchor_7d_avg_gmv']
        features['anchor_category_cvr'] = df['anchor_category_cvr']

        # ===== 商品特征 =====
        features['discount_ratio'] = df['live_price'] / df['original_price']
        features['is_new_product'] = df['is_new_product'].astype(int)

        # ===== 流量前置信号 =====
        features['cart_add_3d'] = df['cart_add_count_3d']
        features['cart_add_7d'] = df['cart_add_count_7d']
        features['preheat_play_volume'] = df['preheat_video_plays']
        features['preheat_interaction'] = (
            df['preheat_likes'] + df['preheat_comments'] + df['preheat_shares']
        )

        # ===== 竞品特征 =====
        features['competitor_live_same_day'] = df['competitor_live_same_day'].astype(int)
        features['competitor_discount'] = df['competitor_discount']

        # ===== 时间特征 =====
        features['is_weekend'] = df['date'].dt.weekday.isin([5, 6]).astype(int)
        features['is_promotion_period'] = df['is_618_or_double11'].astype(int)
        features['live_hour_sin'] = np.sin(2 * np.pi * df['live_hour'] / 24)
        features['live_hour_cos'] = np.cos(2 * np.pi * df['live_hour'] / 24)

        # ===== 交叉特征 =====
        features['cart_price_interaction'] = (
            features['cart_add_3d'] * features['discount_ratio']
        )
        features['anchor_product_match'] = (
            features['anchor_category_cvr'] * features['discount_ratio']
        )

        return features

    def encode_categorical(self, df: pd.DataFrame,
                           cat_cols: list) -> pd.DataFrame:
        """类别特征编码"""
        for col in cat_cols:
            le = LabelEncoder()
            df[col + '_encoded'] = le.fit_transform(df[col].astype(str))
            self.label_encoders[col] = le
        return df
```

## 四、模型设计与训练

### 4.1 模型选型对比

| 模型 | 阶段 | 优点 | 适用场景 |
|---|---|---|---|
| **LightGBM** ⭐ | 第一阶段 | 数据需求低、训练快、部署简单、效果稳定、可解释 | 当前实现（ERP/SIM 数据即可） |
| XGBoost | 第一阶段 | 精度高、正则化强 | 对比验证 Baseline |
| **SaleNet** | 第二阶段 | 融合直播互动数据、专用直播预测 | 数据积累后上线 |
| **TFT** (Temporal Fusion Transformer) | 第二阶段 | 多变量融合、注意力可解释、时序依赖建模 | 直播行为数据丰富后升级 |

### 4.2 LightGBM 模型训练

```python
import lightgbm as lgb
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import mean_absolute_error, mean_absolute_percentage_error
import optuna

def train_lightgbm(X_train, y_train, X_val, y_val,
                   categorical_features=None):
    """LightGBM 模型训练与超参优化"""

    # ===== 超参数搜索空间 =====
    params = {
        'objective': 'regression',
        'metric': 'mae',
        'boosting_type': 'gbdt',
        'num_leaves': 31,           # Leaf-wise 叶子数
        'learning_rate': 0.05,
        'feature_fraction': 0.8,    # 特征采样
        'bagging_fraction': 0.8,    # 数据采样
        'bagging_freq': 5,
        'min_data_in_leaf': 50,     # 防过拟合
        'max_depth': 8,             # 限制深度
        'lambda_l1': 0.1,           # L1 正则
        'lambda_l2': 0.1,           # L2 正则
        'verbose': -1,
        'num_threads': -1,
    }

    # ===== 时序交叉验证 =====
    tscv = TimeSeriesSplit(n_splits=5)
    callbacks = [
        lgb.early_stopping(stopping_rounds=100),
        lgb.log_evaluation(period=100)
    ]

    model = lgb.LGBMRegressor(**params, n_estimators=5000)

    model.fit(
        X_train, y_train,
        eval_set=[(X_val, y_val)],
        eval_metric='mae',
        callbacks=callbacks,
        categorical_feature=categorical_features,
    )

    return model


def hyperparameter_optimization(X_train, y_train, X_val, y_val, n_trials=50):
    """Optuna 超参数自动优化"""

    def objective(trial):
        params = {
            'num_leaves': trial.suggest_int('num_leaves', 15, 127),
            'learning_rate': trial.suggest_float('learning_rate', 0.01, 0.2, log=True),
            'max_depth': trial.suggest_int('max_depth', 3, 15),
            'min_child_samples': trial.suggest_int('min_child_samples', 10, 100),
            'subsample': trial.suggest_float('subsample', 0.6, 1.0),
            'colsample_bytree': trial.suggest_float('colsample_bytree', 0.6, 1.0),
            'lambda_l1': trial.suggest_float('lambda_l1', 1e-4, 10, log=True),
            'lambda_l2': trial.suggest_float('lambda_l2', 1e-4, 10, log=True),
        }

        model = lgb.LGBMRegressor(
            objective='regression',
            metric='mae',
            boosting_type='gbdt',
            n_estimators=3000,
            **params,
            verbose=-1,
        )

        model.fit(X_train, y_train,
                  eval_set=[(X_val, y_val)],
                  callbacks=[lgb.early_stopping(50), lgb.log_evaluation(0)])

        y_pred = model.predict(X_val)
        return mean_absolute_percentage_error(y_val, y_pred)

    study = optuna.create_study(direction='minimize')
    study.optimize(objective, n_trials=n_trials)
    return study.best_params
```

### 4.3 模型评估指标

| 指标 | 公式 | 说明 |
|---|---|---|
| MAE | $\frac{1}{n}\sum \vert y_i - \hat{y}_i \vert$ | 平均绝对误差（与实际销量同量纲） |
| MAPE | $\frac{1}{n}\sum \vert\frac{y_i - \hat{y}_i}{y_i}\vert \times 100\%$ | 百分比误差（业界常用，目标 <15%） |
| RMSE | $\sqrt{\frac{1}{n}\sum (y_i - \hat{y}_i)^2}$ | 对大偏差惩罚更重 |
| R² | $1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$ | 拟合优度 |
| 偏差方向准确率 | 预测方向与实际方向一致的比例 | 判断涨跌方向（供应链决策关键） |

## 五、模型可解释性（SHAP）

```python
import shap
import matplotlib.pyplot as plt

def explain_model(model, X_sample):
    """使用 SHAP 解释模型预测"""

    explainer = shap.TreeExplainer(model)
    shap_values = explainer.shap_values(X_sample)

    # ===== 全局特征重要性 =====
    shap.summary_plot(shap_values, X_sample, show=False)
    plt.title('SHAP Feature Importance')
    plt.tight_layout()
    plt.savefig('shap_summary.png', dpi=150)

    # ===== 单样本解释（为什么预测上调/下调） =====
    shap.waterfall_plot(
        shap.Explanation(
            values=shap_values[0],
            base_values=explainer.expected_value,
            data=X_sample.iloc[0],
            feature_names=X_sample.columns
        )
    )

    return shap_values
```

**SHAP 的供应链价值**：计划员可以直观看到"加购量贡献 +30% 上调、竞品降价贡献 -15% 下调"，从"黑箱预测"变为"可信任决策"。

## 六、预测输出 → 供应链决策翻译

```python
def predict_to_supply_chain_plan(predictions, confidence_intervals):
    """
    将模型预测输出翻译为三级备货策略
    """

    results = []
    for pred, (ci_lower, ci_upper) in zip(predictions, confidence_intervals):
        plan = {
            '保底量': int(ci_lower),          # 自有产线生产（确定性需求）
            '期望量': int(pred),                # 自有 + 外包（基准需求）
            '冲刺量': int(ci_upper),            # 仅备长周期物料（上限需求）
            '策略建议': ''
        }

        # 决策规则
        gap_ratio = (ci_upper - ci_lower) / pred if pred > 0 else 0

        if gap_ratio < 0.3:
            plan['策略建议'] = '需求稳定 → 自有产线全额生产，正常备货'
        elif gap_ratio < 0.6:
            plan['策略建议'] = '中等波动 → 保底量自有产线，超出部分外包 + 预留加班产能'
        else:
            plan['策略建议'] = '高波动预警 → 仅备长周期物料(包材/粒子)，短期物料等直播确认后加急采购'

        results.append(plan)

    return results
```

## 十、关键风险与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| 企业真实数据不可得 | 模型无法训练 | 使用 Kaggle 电商数据集 + 仿真数据生成器验证 |
| 直播黑天鹅事件 | 预测必然有上限 | 不追求100%准确，聚焦"偏差方向正确率"和置信区间 |
| 模型上线后预测漂移 | 准确率下降 | 建立自动复盘机制，监控 MAPE 趋势，触发模型重训练 |
| 前端销售与后端供应链利益不对齐 | 模型输出无人使用 | 输出"三级备货量"而非单一数字，让每个角色各取所需 |

# 特征工程规划文档

> **两阶段策略**：第一阶段用企业侧已有数据（ERP/SIM/商务）做 LightGBM；第二阶段调研直播平台后加入平台侧实时行为数据，升级 SaleNet/TFT。

---

## 一、目标变量构造

| 操作 | 说明 |
|---|---|
| `y = sales.shift(-1)` | 预测明天的销量 |
| 丢弃最后 1 行 | 最后一天无"明天"，无法构成样本 |
| 丢弃前 14 行 | 前 14 天无法计算滚动窗口特征 |

最终可用样本：**200 - 14 - 1 = 185 行**

---

## 二、第一阶段特征（企业侧已有数据，~30 个）

### 2.1 时序滞后特征（历史销量）

| 特征名 | 含义 | 业务解释 |
|---|---|---|
| `sales_lag_1` | 昨天销量 | 最近日销趋势 |
| `sales_lag_2` | 2天前销量 | |
| `sales_lag_3` | 3天前销量 | 中期记忆 |
| `sales_lag_5` | 5天前销量 | |
| `sales_lag_7` | 7天前销量 | 周同比基准 |
| `sales_lag_14` | 14天前销量 | 半月趋势对比 |

### 2.2 滚动统计特征

| 特征名 | 公式 | 业务含义 |
|---|---|---|
| `sales_roll3_mean` | 近3日均值 | 短期趋势 |
| `sales_roll7_mean` | 近7日均值 | 周趋势 |
| `sales_roll14_mean` | 近14日均值 | 半月趋势 |
| `sales_roll3_std` | 近3日标准差 | 近期波动性 |
| `sales_roll7_std` | 近7日标准差 | 周波动性 |
| `sales_roll3_max` | 近3日最高 | 近期峰值（饱和信号） |
| `sales_roll7_max` | 近7日最高 | 周峰值 |

### 2.3 趋势变化特征

| 特征名 | 公式 | 业务含义 |
|---|---|---|
| `sales_trend_3_7` | 3日均值 / 7日均值 | 短期 vs 中期趋势（>1 在涨） |
| `sales_trend_7_14` | 7日均值 / 14日均值 | 是否持续增长 |
| `sales_lag1_vs_roll7` | 昨天 / 7日均值 | 昨天是否异常（>1.5 可能是直播日） |

### 2.4 事件时间特征

| 特征名 | 含义 | 业务解释 |
|---|---|---|
| `days_since_last_live` | 距上次直播天数 | 越久说明越可能临近下次直播，销量可能衰减 |
| `days_since_live_max7` | 近7天内有过直播的天数 | 频繁直播的促销期 |
| `is_post_live_day` | 昨天是不是直播日 | 大播后次日有退货补单的长尾效应 |

### 2.5 日期特征

| 特征名 | 类型 | 说明 |
|---|---|---|
| `day_of_week` | 类别（0-6）| 周内周末效应 |
| `month` | 类别（1-12）| 季节性 |
| `is_holiday` | 布尔 | 已有，保留 |
| `is_weekend` | 布尔 | 已有，保留 |
| `is_month_start` | 布尔 | 月初促销/发薪效应 |
| `is_month_end` | 布尔 | 月末冲量效应 |

### 2.6 价格与折扣特征

| 特征名 | 含义 | 业务解释 |
|---|---|---|
| `price` | 商品售价 | 已有 |
| `discount` | 折扣力度 | 已有 |
| `price_change` | 今天价格 - 昨天价格 | 降价拉升效应 |
| `discount_change` | 今天折扣 - 昨天折扣 | 突然加大折扣 → 需求暴增 |

### 2.7 业务交叉特征（非线性交互）

| 特征名 | 公式 | 业务含义 |
|---|---|---|
| `discount_anchor` | `discount × anchor_fans` | 大主播+大折扣的叠加爆发 |
| `discount_traffic` | `discount × platform_traffic` | 折扣+推流协同效应 |
| `price_vs_competitor` | `competitor_discount / discount` | 竞品优势比（>1 = 我方更便宜） |
| `anchor_traffic` | `anchor_fans / 1000 × platform_traffic` | 大主播+高推流的合力 |
| `discount_sales_momentum` | `discount × sales_roll7_mean` | 折扣×近期销量（惯性放大） |

### 2.8 直接保留特征

| 特征名 | 说明 |
|---|---|
| `anchor_fans` | 主播粉丝量（万） |
| `anchor_gmv_7d` | 主播近7天场均GMV（万） |
| `platform_traffic` | 平台推流指数（0-100） |
| `competitor_discount` | 竞品同期折扣 |

### 2.9 不入模字段（数据泄露或冗余）

| 字段 | 原因 |
|---|---|
| `date` | 非数值，信息已被 `day_of_week`/`month` 捕获 |
| `is_live_day` | **数据泄露**：真实场景下做预测时不知道明天是不是直播日 |
| `sales`（原始） | 已转为 lag + 滚动特征，原始列不直接入模 |

## 三、第二阶段特征（调研直播平台后加入）

> ⚠️ 以下特征需调研抖音/快手/淘宝直播等平台的**数据开放接口**可行性后再决定纳入方式。Demo 阶段不实现，仅标注在技术方案中。

### 3.1 直播实时互动数据（平台 API 可获取）

| 特征名 | 数据来源 | 业务解释 | 调研问题 |
|---|---|---|---|
| `live_viewers` | 直播间实时 | 在线观看人数 | 平台是否提供实时 API？ |
| `live_viewers_peak` | 直播间实时 | 本场最高在线人数 | 峰值时刻往往对应销量爆发 |
| `live_likes` | 直播间实时 | 累计点赞数 | 互动热度代理指标 |
| `live_comments` | 直播间实时 | 评论数 | 用户参与度 |
| `live_shares` | 直播间实时 | 分享数 | 裂变传播力 |
| `live_avg_stay` | 直播间实时 | 平均停留时长（秒） | 停留越长转化率越高 |
| `live_follow_add` | 直播间实时 | 新增关注数 | 主播吸引力即时信号 |

### 3.2 直播前预热数据

| 特征名 | 数据来源 | 业务解释 | 调研问题 |
|---|---|---|---|
| `preheat_video_plays` | 短视频平台 | 预热视频播放量 | 粉丝触达率 |
| `preheat_video_likes` | 短视频平台 | 预热视频点赞 | 内容吸引力 |
| `preheat_cart_add_3d` | 平台电商数据 | 直播前 3 天加购量 | **最强前置信号**（访谈确认） |
| `preheat_cart_add_7d` | 平台电商数据 | 直播前 7 天加购量 | 长期兴趣锚定 |
| `preheat_live_reservation` | 直播平台 | 直播预约人数 | 观看意愿的直接信号 |

### 3.3 主播实时表现数据

| 特征名 | 数据来源 | 业务解释 | 调研问题 |
|---|---|---|---|
| `anchor_current_mood_score` | NLP 情感分析 | 主播当前话术情绪 | 需要语音/文本情感分析（技术难度高） |
| `anchor_speech_rate` | 音频分析 | 语速（快=促销节奏紧张） | 需实时音频处理 |
| `anchor_product_mention_count` | NLP + ASR | 提及本品的次数 | 商品在直播间被反复安利 |

### 3.4 平台生态数据

| 特征名 | 数据来源 | 业务解释 | 调研问题 |
|---|---|---|---|
| `platform_dau_today` | 平台公开/第三方 | 平台当日日活 | 大盘流量（如抖音今天多少人在线） |
| `platform_category_hot` | 平台/第三方 | 同类目是否在热搜 | 品类热度红利 |
| `platform_activity_type` | 平台 | 百亿补贴/超级品牌日/日常 | 活动等级影响预测偏差 ±30% |
| `platform_recommend_pool` | 平台（黑盒） | 是否被放入推荐池 | 最难获取，但影响最大 |
| `same_category_live_count` | 第三方监测 | 同期同类目直播场次 | 竞争密度 |

### 3.5 竞品实时数据

| 特征名 | 数据来源 | 业务解释 | 调研问题 |
|---|---|---|---|
| `competitor_live_now` | 第三方监测 | 竞品是否正在直播 | 实时分流 |
| `competitor_live_viewers` | 第三方监测 | 竞品直播间在线人数 | 分流强度 |
| `competitor_price_change` | 竞品店铺数据 | 竞品是否临时调价 | 直播中突然降价是常见策略 |
| `competitor_sales_estimate` | 第三方估算 | 竞品实时销量估算 | 市场容量感知 |

## 五、处理流水线

```
┌─────────────────────────────────────────────────────┐
│  读 CSV（200行 × 11列）                              │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  构造 y = sales.shift(-1)                           │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  生成 时间序列特征                                    │
│  ├── lag_1/2/3/5/7/14                               │
│  ├── roll3_mean/std/max, roll7_mean/std/max         │
│  ├── roll14_mean                                     │
│  ├── trend_3_7, trend_7_14, lag1_vs_roll7           │
│  ├── days_since_last_live, days_live_in_7d          │
│  ├── is_post_live_day                                │
│  └── price_change, discount_change                  │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  生成 交叉特征                                       │
│  ├── discount × anchor_fans                         │
│  ├── discount × platform_traffic                    │
│  ├── competitor / discount                          │
│  ├── anchor × traffic / 1000                        │
│  └── discount × roll7_mean                          │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  日期特征编码                                        │
│  ├── day_of_week → 类别编码                          │
│  └── month → 类别编码                               │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  丢弃前 14 行（无窗口统计）+ 最后 1 行（无 y）         │
│  有效样本：185 行                                    │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  时序拆分                                            │
│  前 80%（~148 行）→ 训练/验证                        │
│  后 20%（~37 行） → 测试                             │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  输出 X_train, y_train, X_test, y_test               │
└─────────────────────────────────────────────────────┘
```

## 六、第二阶段平台调研规划（标注在文档中，不实现）

| 调研方向 | 具体问题 | 预期收益 |
|---|---|---|
| **抖音开放平台** | 是否提供直播间实时数据 API（观看、点赞、评论）？数据延迟多久？ | 实时互动特征 |
| **抖音电商罗盘** | 商家后台是否可导出加购量、预热视频数据？ | 最强前置信号 |
| **蝉妈妈/飞瓜数据** | 第三方监测平台能否提供竞品直播数据（在线人数、预估销量）？ | 竞品特征 |
| **平台活动日历** | 百亿补贴、超级品牌日等活动是否提前公开？ | 活动类型分类 |
| **数据合规** | 采集竞品数据是否涉及隐私/爬虫合规风险？ | 可行性判断 |

## 第2页：模型策略与核心指标

### 页面布局：左右分栏

**左侧 (55%)：四大优化策略**

```
┌──────────────────────────────────┐
│  策略1: 交互特征                  │
│  discount × is_live_day          │
│  traffic × is_live_day           │
│  → 让模型区分直播日弹性            │
├──────────────────────────────────┤
│  策略2: 双分位数集成               │
│  P50(中位数) + P75(上四分位)       │
│  非直播日用P50，直播日加权P75      │
│  → 供应链需要的是"准备多少"        │
├──────────────────────────────────┤
│  策略3: 样本加权                  │
│  直播日样本权重 = 普通日 × 8       │
│  → 解决类不平衡 (8.6% vs 91.4%)  │
├──────────────────────────────────┤
│  策略4: 多模型集成                │
│  LightGBM + XGBoost 加权平均      │
│  → 降低单模型方差，提升鲁棒性      │
└──────────────────────────────────┘
```

**右侧 (45%)：核心指标仪表盘**

```
┌──────────────────────────┐
│      Live-Day R²          │
│                           │
│       0.736               │
│   解释74%直播日方差         │
├──────────────────────────┤
│  方向准确率   63.3%        │
│  正常天误差   15-20%       │
│  人工基线     ~40%         │
│                           │
│  ┌─────────────────┐     │
│  │  📊 优于人工2-3倍  │     │
│  └─────────────────┘     │
└──────────────────────────┘
```

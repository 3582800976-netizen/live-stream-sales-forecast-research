# 直播电商销量预测 Demo

> **一句话目标**：用一个 Jupyter Notebook 跑通"仿真数据 → LightGBM 预测 → SHAP 解释 → 三级备货建议"完整闭环。

---

## 项目结构

```
sales-prediction-demo/
├── README.md                          # 本文件
├── data/
│   └── generate_synthetic_data.py     # 仿真数据生成器
├── models/
│   └── (训练后保存的模型文件)
├── notebooks/
│   └── demo.ipynb                     # 主演示 Notebook（一镜到底）
└── src/
    ├── feature_engineer.py            # 特征工程
    ├── train.py                       # LightGBM 训练
    ├── evaluate.py                    # 评估 + 可视化
    └── supply_chain_plan.py           # 预测 → 三级备货翻译
```

## 5 张关键可视化

| 图 | 内容 | 答辩要说的 |

| 图1 数据概览 | 时间序列折线图，红点标记直播日 | "直播日的脉冲式峰值是传统预测方法最大的挑战" |

### 第二阶段平台调研规划

| 调研方向 | 具体问题 | 预期收益 |
|---|---|---|
| 抖音开放平台 | 是否提供直播间实时数据 API？数据延迟？ | 实时互动特征 |
| 抖音电商罗盘 | 商家后台是否可导出加购量、预热视频数据？ | 最强前置信号 |
| 蝉妈妈/飞瓜数据 | 能否提供竞品直播数据（在线人数、预估销量）？ | 竞品特征 |
| 平台活动日历 | 百亿补贴等活动是否提前公开？ | 活动分类 |
| 数据合规 | 采集竞品数据是否涉及隐私/爬虫风险？ | 可行性判断 |

## 业务背景

直播电商场景：头部主播单场可卖数千万至上亿，平台要求 48 小时内发货。预测失准 → 库存积压或缺货爆单。本 Demo 展示如何用机器学习替代人工经验预测。
